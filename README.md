# Proyecto Producto en Unity

## Descripcion

Proyecto desarrollado en Unity 6 para la presentación de productos de café artesanal mediante modelos 3D.

## Caracteristicas

* Modelos 3D texturizados.
* Interfaz grafica personalizada.
* Cambio dinamico entre productos.
* Sistema de camaras con Cinemachine.
* Animacion mediante Timeline.
* Musica ambiental.
* Renderizado en tiempo real.
